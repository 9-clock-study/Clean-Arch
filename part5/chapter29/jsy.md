# 클린 임베디드 아키텍처

여기는 임베디드라 잘 모르겠음

- 소프트웨어는 닳지 않지만, 펌웨어와 하드웨어에 대한 의존성을 관리하지 않으면 안으로부터 파괴될 수 있다.
- 안드로이드 앱 개발자 역시 업무 로직을 안드로이드 API로부터 분리하지 않는다면 펌웨어를 작성하는 셈이다.

## 켄트백의 소프트웨어를 구축하는 세 가지 활동

1. 먼저 동작하게 만들어라 : 동작이 없으면 망함 (구현)
2. 그리고 올바르게 만들어라 : SOLID 되게 (리팩터링)
3. 그리고 빠르게 만들어라 : 성능 요구사항 (리팩터링)

- 앱이 동작하도록 만드는 것 = 앱-티튜드 테스트

하드웨어가 만들어지기까지 오래걸린깐 테스트도 어렵고, 그러니깐 HAL 사용해서 인터페이스를 활용해 계층적 아키텍처로 분리하라는 것이 임베디드 핵심인것같음
