# ISP

불필요한 인터페이스를 구현하게 하지말자

인터페이스를 작은 단위로 분리하자!

```ts
interface Phone {
  photo();
  charge();
  bioAuth();
}
```

이런 인터페이스가 있을 때 최신 기종은 되고 옛날 노키아 폰은 바이오 인증 이런건 안된단 말이지
글면

```

class nokia implements Phone {
  bioAuth() {
    ...옛날꺼라 바이오 인증이 없습니다.
  }
}
```

사용하지도 않는 메서드를 이렇게 구현해야됨

# 결론

불필요한 메서드가 있는 인터페이스에 의존하면 예상 못한 문제 발생 가능성이 높아지니 되도록이면 필요에 맞게 인터페이스를 작게 줄여라~
