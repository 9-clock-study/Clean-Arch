잘 설계된 컴포넌트라면 반드시 독립적으로 배포 가능해야한다.

# 재배치성

로더를 활용해 기존 고정된 메모리가 아닌 다른 주소에 재배치 할 수 있는 형태의 바이너리를 생성하도록 컴파일러를 수정하자는 것

external reference : 프로그램이 라이브러리 함수를 호출한다면 컴파일러는 라이브러리 함수 이름을 외부 참조로 생성했다.  
external definition : 라이브러리 함수를 정의하는 프로그램이라면 컴파일러는 해당 이름을 외부 정의로 생성했다.  
linking loadaer : external definition을 로드할 위치가 정해지면 로더가 external reference를 external definition에 링크

## 링커

프로그램이 커지는데 반해 링킹로더는 느렸음
로드와 링크가 두 단계로 분리, 프로그래머가 느린 부분(링크)을 맡았음 linker라는 별도의 애플리케이션으로 처리 -> 링크가 완료된 재배치 코드를 만듦

그러다 하드웨어의 발전으로 링크 시간 대폭 감소 -> 로드, 링크 시간 짧아짐 -> 컴포넌트 플러그인 아키텍처
